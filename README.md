## 它做什么

每天 **20:27**、**20:57**（上海时区）自动跑：

1. 若后天对应星期的 `启用` 为 `false`，立即结束，不登录
2. 用学校统一身份认证（CAS）登录图书馆
3. 按当天的时段配置提交预约：默认一单 7:00–22:00，也可配置多个时段（如 7–9、10–13、18–20）；`name` 为区域名时在该区域随机抽座，为 `自定义` 时用文件底部的座位号
4. 座位被占会换一个再试；某时段已约过就跳过，继续约后面的

20:57 是补跑。不要反复手动点运行。

## 配置
 1. fork本仓库
 2. 点击仓库中的 `setting` 标签， 选中 `Secrets` 选项卡（Settings → Secrets and variables → Actions）
 3. 点击 `New repository secret` 按钮，新建环境变量。

   | 环境变量名| 说明        | 用途                                              |
   |:----------|:------------------------------------------------|:--------------|
   | `SCHOOL_ID` | 你的学号      | 用于登录[杭电智慧图书馆](https://hdu.huitu.zhishulib.com/)（经学校统一身份认证平台跳转） |
   | `PASSWORD` | 学校统一身份认证密码（即信息门户密码） | 用于登录学校统一身份认证平台 |
   | `SCKEY`（选填） | 微信推送服务    | 详见 [Sever酱](https://sct.ftqq.com/) 配置微信推送打卡结果   |

![示范](docs/img1.png)

本地运行时：

```bash
export SCHOOL_ID='学号'
export PASSWORD='信息门户密码'
python main.py
```

## 设置预约时间
 1. 点开 `user_config.yml` 文件
 2. 修改其中日期所对应的设置。默认七天均为 `启用: false`，要约哪天把那天改为 `true`。
 3. 区域名、固定座位号和座位 ID 范围（含端点，不连续区间分行）写在 `user_config.yml` 注释里，指定座位只需改这个文件。

 | 名称      | 值                                | 功能        | 示范                       |
|---------|----------------------------------|-----------|--------------------------|
| `启用`    | `true`/`false`                   | 是否预约「后天」落到这一天 | 启用: true                 |
| `name`  | `二楼西`/`二楼东`/`四楼`/`六楼`/`十二楼`/`自定义` 等 | 预定座位位置    | name: 二楼西               |
| `开始时间`  | 24小时对应数字                         | 使用座位开始时间  | 开始时间: 7 (代表 7:00 开始) |
| `持续小时数` | 数字                               | 使用座位小时数   | 持续小时数: 15（即 7:00–22:00） |
| `时间段`  | 列表，每项为 `开始时间`/`持续小时数`；与上面两字段二选一，时段不可重合（首尾相接可以） | 一天预约多个时段 | 时间段：<br>  - 开始时间: 7<br>    持续小时数: 2 |
| `自定义`   | yaml 列表，内容为座位号（需将 `name` 改为 `自定义`） | 使用自定义座位号  | 自定义：<br>  - 60710         |

 4. 保存文件并点击 `Commit changes` 按钮

## 启用脚本
 1. 点击仓库中的 `Actions` 标签
 2. 点击 `I understand my workflows, go ahead and enable them` 按钮

![示范](docs/img3.png)
